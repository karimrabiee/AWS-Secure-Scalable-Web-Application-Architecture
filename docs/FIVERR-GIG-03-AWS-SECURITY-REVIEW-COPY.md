## Description
Want a clearer picture of security risks in selected AWS resources?

I will review an agreed, limited set of AWS configuration evidence and provide a prioritized findings report with the affected resource, why it matters, practical remediation guidance, evidence references, and limitations.

Possible review areas (agree before ordering):
- IAM users, roles, policies, and trust relationships.
- S3 public-access settings and bucket policies.
- Security groups and exposed network paths.
- CloudTrail and selected logging configuration.
- Encryption settings for selected storage/database resources.
- Public exposure of selected EC2, RDS, or load-balancing resources.

The review starts read-only. You receive a concise report with severity, evidence, impact, remediation steps, and limitations. Remediation is separate unless explicitly included.

This is not a penetration test, formal audit, compliance assessment, AWS Well-Architected Review, or guarantee that an account is secure. Findings depend on the resources and evidence in scope.

Message me before ordering with AWS services, region, resource count, and whether you want read-only review or separately scoped remediation. Never send root credentials, passwords, access keys, private keys, or unredacted sensitive data.

## FAQs
**Is this a penetration test?** No. It is a limited configuration review based on agreed evidence and resources.
**Do you need administrator access?** No. Start with redacted exports and customer-run read-only commands. Temporary access, if necessary, must be least-privilege and time-limited.
**Will you certify compliance?** No. No compliance certification or attestation is issued.
**Will you fix every finding?** The report includes guidance. Implementation is separately scoped and approved.

## Scope gates
No penetration testing, exploitation, destructive testing, HIPAA/PCI/SOC2/ISO/FedRAMP certification, claims of complete security, unapproved live changes, root credentials, or findings about resources outside the agreed evidence.
