## Description
Stuck on a Terraform or AWS deployment error?

Share the exact command, error output, relevant configuration, and what changed before the issue appeared. I will investigate the agreed issue, explain the likely root cause, and provide a focused fix with validation steps.

Typical areas:
- Terraform init, provider, module, plan, and validation errors.
- Backend configuration and state-locking diagnosis.
- IAM AccessDenied and policy/trust relationship troubleshooting.
- GitHub Actions failures related to AWS authentication/deployment.
- Common networking and resource dependency configuration errors.

You receive a root-cause explanation, the agreed code/configuration change or exact remediation steps, and the validation result.

Please contact me before ordering. One order covers one clearly described issue in one repository/workflow and one environment unless agreed otherwise. Never send passwords, root credentials, access keys, private keys, state files, or unredacted secrets.

## FAQs
**Can you debug any AWS issue?** No. I focus on Terraform, IAM/OIDC deployment, and common infrastructure configuration errors. I confirm fit first.
**Can you log in to my AWS account?** Not by default. We start with logs and redacted configuration. Any remote access must be separately agreed and least-privilege.
**Will you change production?** Not without explicit approval, a reviewed change plan, and rollback approach.
**What if the problem has multiple causes?** I explain what is in scope and request approval before expanding it.

## Exclusions
No 24/7 incident response, emergency on-call, guaranteed recovery times, data recovery, destructive state surgery, production migrations, unrelated application debugging, penetration testing, compliance work, or unauthorized systems.
