## Description
Need help with Terraform on AWS? I can organize, troubleshoot, or implement a clearly scoped infrastructure change with readable code and a practical handover.

Depending on the agreed scope, I can:
- Create or refactor reusable Terraform modules.
- Configure selected AWS networking and infrastructure resources.
- Review variables, outputs, naming, and environment separation.
- Diagnose init, plan, state, provider, and dependency errors.
- Add formatting, validation, and infrastructure checks.
- Document deployment, review, and teardown steps.

You receive the changed Terraform files, validation output, assumptions, and handover notes. Message me before ordering with your repository structure or exact error, AWS services, region, and desired result. Redact secrets; never send root credentials or long-lived access keys.

This service excludes unbounded migrations, production incident response, compliance certification, and destructive changes without explicit approval.

## FAQs
**Can you work with existing Terraform?** Yes. I review relevant files and confirm scope first.
**Will you run apply in production?** Only if explicitly agreed after reviewing the plan, access model, rollback approach, and impact.
**Do you guarantee no downtime?** No. Terraform changes can affect live resources. I explain proposed changes and risks before apply.
**Can you fix state issues?** I can investigate backend, locking, provider, import, and state-reference problems. State manipulation requires an agreed backup and recovery plan.

## Exclusions
No production apply/destroy without explicit approval; no deleting/replacing resources just to make a plan pass; no secrets, state files, or private keys shared through chat; no broad admin permissions as a shortcut; no compliance certification, penetration testing, or guaranteed savings; no EKS/Kubernetes production build-outs.
